## 2. Purpose

本阶段只冻结并验证一个条件式强基线：如果未来 R0/R1 产生合格且 sealed 的 RGB-text Reward oracle，能否在不训练 Reward components 的前提下，用每个 VAE 独立的 Projector 将 native latent 映射到冻结 Reward interface。

R2P-0 不是 Projector 实验结果。它不训练 Projector、不生成 R2P latent cache、不读取 Projector DEV、不 decode RGB、不读取 LOCKBOX，也不使用 MPS/GPU/AutoDL/network。

## 5. Parameters

### Strong Projector

```text
native latent
-> patchify 64 tokens
-> Linear(raw_dim, 128)
-> learned 2D position [64, 128]
-> LayerNorm(eps=1e-5)
-> 3 pre-LN Transformer blocks
-> learned query + 4-head cross-attention
-> MLP 128 -> 256 -> d_R
-> frozen oracle normalization
```

- SD：`[4,64,64] -> 64 × 256`
- FLUX：`[16,64,64] -> 64 × 1024`
- DCAE：`[32,16,16] -> 64 × 128`

### Shallow baseline

```text
patch projection -> mean pool 64 tokens -> Linear(128,d_R) -> oracle normalization
```

严格不含 position embedding、LayerNorm、Transformer、cross-attention 或 hidden MLP。

### Frozen training and decision contracts

- Budget：`max_updates=2000`，`warmup_updates=100`
- Batch：P-SUP=`256 pairs`；Anchor/PERM/Shallow=`128 unique images`
- 只看 final checkpoint；禁止 DEV checkpoint selection 和 early stopping
- Optimization：必须完成精确 2,000 updates、finite、parameter changed、reload PASS、loss improvement `>5%`，且不得连续 5 次 gradient norm `<=1e-12`
- Noncollapse：variance `>1e-6`、active fraction `>=0.50`、effective rank `>=min(8,0.125*d_R)`、Reward score std `>1e-4`
- Statistics：common `20,000` 次 prompt/base-ID connected-group bootstrap；one-sided 95% 用于 decision，central 90% 只作 descriptive
- Ratio：P-SUP point/lower `>=0.80/0.70`；Anchor|SUP `>=0.70/0.50`；denominator `<=0` undefined，`(0,1e-4)` unstable，禁止 epsilon/clip/abs/delete replicate
- Decode taxonomy：`INVALID_DECODE_PIPELINE`、`DECODED_RECONSTRUCTION_REWARD_INADEQUATE`、`DECODE_BASELINE_VALID`
- MPS：未来在 sealed DEV batch 上 replay 两次；FP32 abs/rel=`1e-6/1e-5`，BF16=`2e-3/2e-3`，max-logit drift `>2e-3` 失败；本阶段未运行 MPS

## 8. Analysis

### 能说明什么

- 条件式 R2P 协议、architecture、budget、controls、statistics、ratio、decode、MPS 与 artifact inventory 已冻结。
- CPU-only publisher/verifier 能 fail closed 地约束 exact repo root、clean predecessor、legacy metadata、17-file membership、canonical JSON、receipt、blocked command 与 pinned Git tree。
- Legacy 14,918-image full-authority cache 不能被误当成 TRAIN/DEV scoped training cache或 benchmark cache。

### 不能说明什么

- 没有合格 R0/R1 oracle，不能执行或解释 R2P-1。
- 没有训练任何 Strong/Shallow/P-SUP/P-ANCHOR/PERM Projector，因此没有 optimization、noncollapse、Reward retention 或 architecture comparison 结果。
- 没有证明 native latent 的 Reward ceiling、shared U 是否必要、Reward transfer、fresh confirmation、cross-distribution generalization 或 unseen-VAE onboarding。

- 该空目录经审计后用 `rmdir` 删除；随后以 actual-shape failing test 修正 reader，完整回归通过后重新发布。该问题不是科学失败，也没有读取额外 payload。
- 自包含 receipt 只能检测非协调篡改；对“同时改 artifact 并提交新 Git commit”的协调替换，必须使用树外公布的 commit ID 作为 trust pin。未 pin 的 `HEAD` match 不能称为签名。
