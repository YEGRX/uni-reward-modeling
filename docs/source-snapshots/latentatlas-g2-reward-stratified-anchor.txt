# LatentAtlas G2-R Minimal Reward-Stratified Anchor Probe

> [!IMPORTANT]
> 本实验检验的是：用 train preference labels 选择 task-informed anchors，能否主动诱导更 Reward-aligned 的跨 VAE relation。它不检验 natural shared Reward geometry，也不能证明 held-out Reward 泛化。

## 1. Date

2026-08-14

## 2. Purpose

在 [[latentatlas-g2-minimal-reward-local-geometry]] 的冻结 Random-64 基线上，只改变 Anchor selection：从 train preference graph 的 component-local Bradley–Terry utility 中构造 `16 Low + 32 Mid + 16 High` 的 Reward-Stratified-64 bank，比较三 VAE relation-space neighborhood consensus 是否因此更接近 Reward geometry。

核心问题：

\[
\text{Reward-aware landmarks}
\Rightarrow
\text{stronger cross-VAE Reward alignment?}
\]

## 4. Dataset / Input

- Preference source：G0.1 cache-covered induced graph，共 `999` usable pairs、`713` images。
- Split counts：train / validation / test=`605 / 168 / 226`。
- Anchor selection 只接收 `605` 条 train edges；validation/test labels 不进入 BT fitting、stratification 或 selection。
- Train BT graph：`481` images、`149` components；不同 component 的 utility 不做绝对值比较。
- 三 VAE verified clean-latent cache 均覆盖 713 张 reward images；relation output shape 均为 `[713,64]`。
- RGB availability 使用 sealed label-free bundle，并用 canonical decoded-RGB SHA-256 验证，而不是 encoded file hash。

### Reward-Stratified bank

- component 内使用 tie-aware average rank percentile：`(average_rank-0.5)/n`；`<1/3` 为 Low，`>2/3` 为 High，其余为 Mid。
- 两个 zero-variance BT components 的候选全部进入 Mid，不人为制造高低排序。
- 64 个 typed quota slots 与 eligible components 做固定种子的 maximum bipartite matching。
- 最终配额：Low/Mid/High=`16/32/16`。
- 64 anchors 来自 64 个不同 preference components，达到可行的最大 component coverage=`64`。

## 5. Parameters

- Relation operator：`global_cosine`，不增加额外 normalization。
- `K=64`，`k=10`；不调 K/k，不换 operator，不 reroll。
- 每个 VAE 在自己的 `[713,64]` relation space 中找 top-10 neighbors。
- RewardGap、same-component matched Random、1000 次 bootstrap、`Spearman(C,-RewardGap)` 完全复用 G2-v0。
- Reward axis：`mean(similarity to High)-mean(similarity to Low)`；不训练模型。

source-workspace/.venv/bin/python \

## 7. Results

### Primary comparison

| Anchor Type | C≥2 Gap | C=1 Gap | Random Gap | Consensus Spearman |
|---|---:|---:|---:|---:|
| Random-64 | 1.323147 | 1.300765 | 1.337475 | -0.001502 |
| Reward-Stratified-64 | 1.406851 | 1.176906 | 1.443182 | 0.019096 |

关键差异：

- Random-64：`C≥2−C=1=+0.022382`。
- Reward-Stratified-64：`C≥2−C=1=+0.229946`，方向明显更差，而不是更好。
- Reward bank 的 Spearman 从 `-0.001502` 变为 `+0.019096`，但 95% CI=`[-0.066639,0.106890]`，仍跨 0 且效应接近 0。
- Reward bank 的 C=3/C=2/C=1/Random mean RewardGap=`1.400881/1.415403/1.176906/1.443182`。

### Reward-axis vs BT utility

| VAE | Spearman rho | N |
|---|---:|---:|
| SD-VAE | 0.064421 | 481 |
| FLUX-VAE | 0.017892 | 481 |
| DC-AE | 0.043565 | 481 |

三者均为极弱正相关；而且这些数值在 anchor selection 所使用的同一 train BT utility 上计算，属于 in-sample diagnosis，不能外推 held-out prediction。

### Cross-VAE reward-axis consistency

| VAE Pair | Spearman rho | N |
|---|---:|---:|
| SD / FLUX | 0.913010 | 713 |
| SD / DC-AE | 0.895949 | 713 |
| FLUX / DC-AE | 0.938944 | 713 |

Reward axis 在三个 VAE 间高度一致，但它与 BT utility 的相关接近 0。这说明 anchors 确实诱导了共享方向，不过该方向主要不是当前 human-preference Reward 方向。

Decision gate：**Case C**。

## 8. Analysis

Reward-Stratified anchors 没有把 consensus 转化成更小 RewardGap。最直接的反证是 `C≥2−C=1` 从 Random bank 的 `+0.022382` 恶化到 `+0.229946`；虽然 consensus Spearman 略转正，但数值很小且区间跨 0。

Reward-axis 结果提供了额外解释：三个 VAE 读出的 axis 彼此高度一致，却几乎不跟 BT utility 对齐。因此“跨 VAE 一致”与“Reward-aligned”是两个不同条件。当前 task-aware landmark selection 能制造共享 reference direction，但只改变 Anchor selection 不足以把它变成 Reward geometry。

这次失败发生在对 Reward-aware anchor 最有利的 train in-sample 诊断中，因此对“继续手工优化 Anchor bank”构成较强的停止信号；但它仍不等价于证明 raw clean latent 中没有 Reward information，也不评估 learned U。

## 9. Problems

- Anchor selection 与 RewardGap/reward-axis-vs-BT 共享 train component utility；实验没有定义 validation/test component utility，因此没有 held-out Reward generalization estimate。
- Pair-row bootstrap 没有建模 query/component clustering；CI 仍是轻量探索性统计。
- Cross-VAE axis 高相关可能反映三 VAE 共享的外观/内容方向，不能因其一致就称为 Reward direction。
- Cache 只覆盖 713 张图，不代表完整 6,632-image G0.1 数据。
- Formal CLI 的首次启动暴露共享 `.venv` editable package 指向另一 worktree；最终 runner 已强制优先加载本分支 `src/`，以隔离同时进行的实验。

## 10. Next Steps

1. 按冻结停止条件，不再尝试其他 High/Mid/Low 比例、seed、K、k 或 relation operator。
2. Anchor 正式降级为 onboarding/reference tool，不继续作为手工 task-aware canonicalization 主线。
3. 若未来另行批准 learned-U 实验，主输入应为 raw clean latent，监督应直接来自 Reward；当前 relation 最多作为弱 auxiliary/reference。
4. 下一步规划、复核和写作均为 CPU-only/no-server。只有明确开始新编码或训练时才需要重新启动 GPU。
