# LatentAtlas 投稿实验证据补全 Submission Evidence

## 1. Date

2026-10-09；身份LATENTATLAS_SUBMISSION_EVIDENCE_20261009_R1。已完成E0/E1与E2真实CPU拟合；新REC任务评分未运行，不宣称投稿贡献链闭合。

## 2. Purpose

围绕实际28页中文稿建立由合理baseline、真实输出和有效评价支撑的贡献证据。先复用合法缓存，再固定最小REC对照，不因Q32导数资格失败停止无关REC。

## 3. Code Version / Commit

独立目录：scripts/latentatlas-submission-evidence-20261009-r1/。原研究代码只读；本轮未提交原研究Git仓库。代码/配置/结果SHA由归档manifest绑定。公开参考Latentis固定commit800699f9fd5a98880adac40590e075aaffb87ab9，方法为密集空间适配，不称忠实复现。

## 4. Dataset / Input

DEV28：252图、1008对、4流4032逐流判断；已开发消费。NEW56：504图、2016对、4流8064；与旧adapter组互斥，但父pool已用于source qualification。独立内容单位分别28/56个完整connected groups，不是流或pair数。

E2：同原FIT64/VAL64；Cosmos同图T0、DC-AE同图T1。新ridge/SVD拟合不查Reward、不用目标偏好标签。数据用途、源/目标、模型与缓存身份见资产合同表。

## 5. Parameters

旧Accuracy严格tie=0；agreement排除reference tie、student tie=.5；逐流和ensemble分别列；原组权重与noise coupling保持。NEW N/G非tie分母8017/8026；DEV N3999。组bootstrap不覆盖初始化或Anchor抽样。

E2 ridge λ∈{0,.001}仅VAL坐标选择，SVD一个固定候选；FIT-only标准化、每图等权；共享矩阵Cosmos272/DC-AE528参数。部署FP32 affine→BF16，再加canonical noise。Cosmos源tensor identity-grid资格已独立CPU检查；DC-AE变量网格仍需核对。

## 6. Command

从脚本目录运行：

    python -m unittest discover -s tests
    python analyze_cache.py --output results/e1-replay-new-identity
    python evaluate_translations.py --manifest configs/e2-cosmos-forward-r1.json --output /tmp/unused

第三条仅prepare-only，无模型调用；新GPU执行必须新增范围授权。旧身份/输出不覆盖，继续前先查看回执。

## 8. Analysis

REC对合理已有方法的独立任务增量尚未建立；锚点坐标优势不能替代行为对照。少Anchor相对优势与稳定性未证；Cosmos开发near-native保留。当前无事前理论预测，只有后验精确风险分解与经验界检查。HPS/PickScore仍是decoder复合路径；多个latent-native Reward/梯度引导有效性没有证据。

中心化与自由offset形式可能等价；局部求解仅产生指定线性目标的候选，对真实holdout各自增量未识别。新Q32严格G一致率C32高于Q32，风险下降不等于排序保持。

## 9. Problems

E2 R1旧teacher格式读取错误、R2名义网格断言失败，R3修复后完成CPU拟合；工程失败不作为模型低分。首次E1审查发现DEV trust root缺口，已修复并保留失败测试/回执。E2独立CPU充分量精确一致、部署VAL最大差1.77e-8；GPU代码根/计时问题已修正，但GPU集成未运行。

旧Q32仍为LOCAL_METHOD_NUMERICALLY_UNQUALIFIED，FD1.086510520>0.20；旧E2/MAIN8未执行。新前向VAL独立归档；新MAIN8在首个科学评分前因文本张量指纹与旧缓存不一致被拦住，科学评分0；另一个聊天正CPU定位，尚无效果终点。

## 10. Next Steps

优先只运行Cosmos两冻结基线真实任务评分：16,128科学+16技术DiNa、28唯一prompt、GPU硬上限90分钟；训练/反向/VAE0，不采购。新增范围审批已提出一次，尚待回复；旧权限未覆盖它。现有Q32聊天不重复启动、不终止。DC-AE部署资格和后续32,256评分另列计划。
