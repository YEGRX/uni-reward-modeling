# R18 × DiNa 真实缓存选图 Pilot

## 1. Date

2026-10-10。**NO_GAIN**；旧数据回顾性交叉拟合。固定案例8张原图已取回，真实照片面板完成；独立确认B NOT_RUN。

## 2. Purpose

Research gap：有限带噪评分的条件指数恢复，是否能改善冻结奖励模型在真实候选上的最终选图？主端点是人类直接比较，不用模拟KL代替应用收益。

## 3. Code Version / Commit

未创建提交/PR。新增 `src/lrc/r18_visual.py` 和 `r18_visual_run.py`；复用R18 polynomial/product_moments。主V2固定2.2414，保留V1与高阶消融；不增加V3/V4。源码/预测/选择hash在输出封存。独立review已复现预测、方向与选图；最终R2修复封存顺序，原R1保留，7个数值文件逐字节相同，不是新数据确认。

## 4. Dataset / Input

旧28 prompt groups、252图、1008完整人类pair。原生native每图固定最小pair ID的一次四流，前两流Y，后两流H，K2。HPS新版O原图mu与pixel/PNG/prompt身份匹配，训练折中位数二元U；human不入拟合。新56图组零重叠但缺clean teacher，单独审计，不拼接。

## 5. Parameters

4外折，每折21组189图训练、7组63图评价；强L2 Logistic正则.1/1/10在训练组三内折选，均选10。λ0与.125固定；真实图片受控q_hat抽样，非GRPO反馈。每组Best4重复20共享子集、Best9全集；28组bootstrap10000，主两比较97.5%区间；最小有意义胜率55%。

输入tanh改变scorer/目标；四格Y、跨prompt共享、未知p_min和有限评分q_hat均不能直接继承原二元IID固定prompt统一保证。输出是指定HPS二元质量代理，不是完整连续质量分布。

## 8. Analysis

高阶乘积矩、结构处理、正归一化实际执行且保留。V1阈值.900–1.148全部归零对比；V2阈值.010–.020全部保留，与unpooled一致。主最高分并列64.46%，Best9 75%；粗分组是有证据的信息瓶颈。tanh与原raw平均选择一致，不支持把失败归于变换排序。V2 Brier .19985小于reference .20350，但弱于Logistic .17652；不能据此称应用成功。

当前适配器缺乏可信选图收益，论文方法贡献/novelty未获经验支持。真实指数积分精确风险无法从此bank识别，INCONCLUSIVE；不能把这个负结果扩大为所有R18理论无价值。
