## 2. Purpose

Research gap：此前缺少 DiNa 官方 checkpoint 在 HPDv3 源任务上的 sanity/parity check。SRC0 使用当前已冻结、尽可能 paper-matched 的 inference protocol，检验是否恢复论文级别 Reward 能力；属于 source-domain parity / qualification，不是整篇论文 exact reproduction，也不重新训练或优化 DiNa。

LatentAtlas 核心：已 qualified 的 frozen Reward function，能否通过低成本 representation/interface registration 被异构/新 VAE 在 **0 target Reward labels** 下复用。跨所有 preference datasets 的 OOD 泛化不属于当前主线；不会因 External 差转向改进 DiNa、重训 Reward head 或 universal preference modeling。

## 8. Analysis

本次是已声明工程协议下的源域能力验证（best-evidence source-domain validation），不能声称精确复现论文。75.04% 保留为文献参考及预先注册的操作性门槛，无法证明与作者采用完全相同的评测成员与预处理；也不是 fresh confirmation。


### 四层结论与边界

| 结论层 | 回答什么 | 解释边界 |
|---|---|---|
| DiNa source-domain qualification | 当前官方 checkpoint/runtime 在冻结 HPDv3 源任务上是否 qualified | PASS 才建立本轮源域资格；FAIL/INDETERMINATE 为 parity 尚未建立并停止推进，不能据此否定全部DiNa用途或整个LatentAtlas |
| Dataset/task shift | 同一冻结 Reward/runtime 在 source 与 external 上的差异 | 差异用于诊断与局限；不能由External低分直接否定source能力，也不能只据差异确定唯一因果 |
| Representation/interface registration | 异构VAE能否以低成本、0 target Reward labels 完成注册 | 对齐/重建成功不自动证明target Reward功能恢复 |
| Target Reward reuse | 注册后的target路径能否复用已qualified的冻结Reward功能 | 需对应target评估指标和对照，不能由source PASS或registration单一指标替代 |

旧 DINA0 约50%的external结果不能直接与论文HPDv3数字比较；保留它的诊断价值，补上source sanity check。现有冻结规格、14,400 pairs、timestep、seed、方向、preprocessing、aggregation、阈值与判定一律不因本补充改变，也不根据中间结果调参。

公开材料无法确认的具体论文评测成员与预处理绑定继续标为 **unresolved**。本轮“尽可能paper-matched”不消除这些不确定性。
