# LatentAtlas U4-A4 Reward-Free P4096 Cross-Fit Correspondence Specificity

## 1. Date

2026-08-24（冻结设计与实施计划日期为 2026-08-23）

## 2. Purpose

U4-A4 是 U4-A3 之后唯一一次 `development-only / adaptive follow-up / non-confirmatory / reward-free / reused nonfresh evaluation cohort / CPU-only` 的 P4096 cross-fit correspondence specificity audit。Run identity 为 `U4A4_DEV_REWARD_FREE_P4096_CROSSFIT_CORRESPONDENCE_SPECIFICITY`。

它只回答一个有限问题：用注册的 P4096 source rows 训练时，若 target pairing 是 correct canonical target 或五个冻结 whole-row permutation null，参数量匹配的 flat affine family F 与 invariant nonlinear family N 能否在 identity-disjoint、但历史上已经暴露的 H1105 development cohort 上表现出稳定的 correct-over-all-nulls advantage。

这不是 Reward 实验，也不是 fresh holdout、independent test、confirmatory authority 或 generalization experiment。它不能建立 canonical U、universal U、Reward transfer、unseen-VAE transfer、真实部署能力，也不能把 H1105 称为 unseen/fresh/test cohort。

相关页面：[[latentatlas]]、[[latentatlas-u4a3-reward-free-k64-parameterization-factorization]]、[[representation-alignment]]、[[latent-space]]。

## 5. Parameters

- `F`：seedless flat affine，连续 row-major flatten `32×16=512`，加 bias 后映射到 raw 64-d target；`32,832` 参数、CPU `float64`，一次 `[4096,513]` thin SVD 复用到 6 个 RHS。
- `N`：shared-token `Linear(16,404) → GELU → Linear(404,64) → mean over 32 tokens`；`32,788` 参数，无 position/identity/VAE/index/lookup input。
- N seeds：`20260823/20260824/20260825`；每个 seed 在全部六个 pairings 上使用相同 initial state 与 batch schedule，但重新加载独立 model/optimizer。
- N optimization：CPU `float32`，AdamW，batch=`64`、updates=`10,000`、identity presentations=`640,000`、effective epochs=`156.25`、`lr=1e-3`、`weight_decay=1e-4`，global Charbonnier loss `sqrt(mean(error²)+1e-12)`；无 scheduler、early stop、best checkpoint、warm start 或 resume。
- H aggregate metrics：`float64` NRMSE/RMSE/MSE、mean cosine、R@1/R@5/MRR、mean/median rank、output effective rank 与 variance mass；off-positive similarity `>=` positive 时计为 outrank。
- Bootstrap：fixed-cohort paired query bootstrap，seed=`2026082404`、20,000 replicates、sample size=`1105`；lower bound 是排序后 zero-based index `999`，无插值。
- Registered gates：`L_E >= 0.05`、`L_R1 >= 0.02`、`L_M >= 0.02`；N 还必须先通过 18-cell optimization adequacy。
- Two-phase authority：real P4096 access 前 durable attempt receipt；24 个 artifacts 完成后 immutable fit seal；H access 前 durable H receipt；随后一次 materialization、顺序评价 24 artifacts，不持久化 per-query H payload。

## 8. Analysis

1. U4-A3 只证明 K64 上 F/N 能同时插值 correct 与 null，不能证明 correspondence specificity。U4-A4 把拟合 population 扩到 P4096、在 identity-disjoint H1105 上 cross-fit 后，F 与 N 的 correct 都稳定胜过全部五个 null，且三项 registered lower-bound gates 同时通过；这建立了当前历史开发 cohort 内的 correspondence-specific signal。
2. 信号不是单一 architecture 偶然：parameter-matched F 与 N 都通过，故冻结 headline 是 cross-family advantage。N 的点估计更高，但 U4-A4 没有注册 F-vs-N model-selection gate，不能据此宣布 N 为最终架构。
3. Correct mapping 并非完美 coordinate recovery：F/N correct H NRMSE 约为 `0.226` / `0.186`，R@1 约为 `0.364` / `0.462–0.471`。因此本实验支持“正确配对具有可识别优势”，不等于 raw coordinate 已完全恢复或 universal canonical target 已证明。
4. Query bootstrap 只度量固定 H1105 cohort 上、固定 artifacts 下的 conditional query robustness。它不是 training-randomness CI、population-generalization CI 或显著性检验。
5. 结果把解释空间从“小样本纯 interpolation”推进到“大量配对、历史开发 cohort 上的 correct/null discrimination”，但仍没有跨越 Reward-free registered development audit 到 fresh functional confirmation 的证据边界。

## 9. Problems

- H1105 是 historically exposed development evaluation cohort；本次 one-shot 只约束 U4-A4 内部 access，不能抹去此前 U4-A formal/audit 已各打开一次的历史。
- 当前是 dense transductive paired onboarding：P4096 使用大量 paired identities，不能称为 low-cost anchor onboarding。
- 五个 null 是相关的 frozen falsification controls，不是独立抽样的 significance distribution。
- 为遵守 authority boundary，工件不持久化 per-query H predictions、ranks、embeddings、IDs 或 bootstrap samples。因此 disk-only verifier 无法独立重算 H predictions 或 bootstrap；它验证 sealed evaluator/code provenance，并从已保存 aggregates 重算 gate 与 decision。这是明确的 verifier trust boundary。
- 未访问 Reward label/checkpoint/model/evaluator，故所有 functional Reward 结论仍未知。
- 本实验未测试新 VAE、fresh holdout、larger K、模型选择或现实数据分布；这些都不能从当前正结果外推。

## 10. Next Steps

1. 当前执行 hard stop：不自动设计、创建或运行 U4-A5、U4-B、Reward、fresh holdout、larger K、新 VAE 或任何其他 follow-up。
2. 仅作为建议、并未执行：先进行 scientific review；如果之后有独立审批与真正未触碰的 authority，再冻结单一协议检验这种 structural correspondence specificity 是否能转化为 Reward functional specificity。不能复用当前 H1105 作为 fresh confirmation。
3. 不应依据本实验的 N 较高点估计直接做 architecture selection；若未来需要选择，必须另行冻结选择 authority 与 gate。
