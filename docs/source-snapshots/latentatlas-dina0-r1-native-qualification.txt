# DINA0-R1 外部 DiNa 原生裁判资格检验

## 1. Date

2026-09-14 已完成评分、回传、独立重放与归档。**工程核验 PASS，科学资格 UNQUALIFIED**。最终分类：`DINA_NATIVE_REWARD_UNQUALIFIED_ON_REGISTERED_DEV_AUTHORITY`。DINA1 不启动，当前无需 GPU 或服务器。

## 2. Purpose

独立检验外部冻结 DiNa 经自身 SD3.5 VAE 原生路径，是否能在已消费开发偏好数据上提供可泛化的 Reward 信号。研究缺口（research gap）是区分裁判自身资格与跨 VAE 接口恢复；本阶段无需 Anchor。

## 5. Parameters

RGB 原尺寸，无 resize/crop/pad；official SD3.5 VAE posterior sample → `(z−0.0609)×1.5305` → frozen DiNa。每图固定 canonical latent；u=.1、K_noise=4、prompt length256，算术平均 raw scores。20,000 次共享 connected-group bootstrap，固定 seed20260829036。q05 是单侧95%下界；q05/q95 是中央90%区间。

Baseline/controls：PAIR_RO、GLOBAL_SD、Wrong Prompt。主指标（metrics）：EXTERNAL Accuracy−chance下界>0、相对五个PAIR_RO均值的gain下界>0，以及方向、pair-swap和noncollapse；DIAG point Accuracy>.5与注册方向一致性。没有事后调参或构造概率型指标。

## 8. Analysis

2026-09-15解释补充：本封存结果在当前研究中定位为 **external/OOD diagnostic**。约50%仅描述既定外部数据及runtime，不能直接与论文HPDv3数字比较，也不能据此判定DiNa本身无效。之前缺少的是source-domain sanity/parity check，外部实验并非无价值。原数值、自动UNQUALIFIED及旧DINA1停止记录保持，不回写旧seal。新SRC0/SHIFT0/REG1将分别回答源域资格、dataset/task shift、representation/interface registration和target Reward reuse；见 [[latentatlas-dina-src0-source-domain-parity]]。

Source: `raw/experiments/latentatlas/dina-src0-best-evidence-2026-09-15/research-intent-clarification.md`。

当前固定DiNa原生路径未在注册外部开发数据上证明满足冻结裁判资格。DIAG有限信号不足以支持外部资格；这不等于所有DiNa用途无效，也不否定整个LatentAtlas。PAIR_RO外部区间48.218%–49.642%，不能声称该对照回到chance。Wrong Prompt等诊断不替代主门槛。

新的协议修订解除DINA0与Anchor证明的耦合。旧DINA1-R1和GFI预检仍作为历史独立记录保留。完整解释见 `raw/experiments/latentatlas/dina0-r1-final-2026-09-14/dina0-final-report-zh.md`。
