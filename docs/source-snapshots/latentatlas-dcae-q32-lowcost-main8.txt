# LatentAtlas DCAE Q32 低成本 MAIN8 实验

## 1. Date

2026-10-09。实际执行与交付已结束；科学结论 **LOCAL_METHOD_NUMERICALLY_UNQUALIFIED**。E1固定差分资格失败，按原协议停止，E2/MAIN8未执行。

## 2. Purpose

在固定S2562000、T1/W0、DiNa/PAPER_T04下，比较C32/A32/Q32，仅拟合各32维小参数。先M0/E0/E1/E2；只有固定行动、参考与可比性门槛全部通过才继续MAIN8。完整E3、EP和4K续训不在授权内。

## 3. Code Version / Commit

原S256工作树HEAD `963c6d5`，只读复用；新实验独立运行目录。正式生产合同SHA `524e3be395edf98be8fa46928869b1a5bf84cb69316c1a4a6d0f0dd1c02d0d16`。正式源码、298个继承源码逐文件pins、独立审查、CPU边界测试与第二CPU读回封存。数值r2修复C32不可辨认秩的误准入，保留r1与失败；科学阈值未改。

## 4. Dataset / Input

原56组504图/2016对/4流历史缓存。固定hash MAIN8=8完整组、72图/288对；其6912条原请求的完整source/prompt/noise/receipt绑定已远端核。原FIT256、VAL64互斥；392份S256预测绑定，最小官方caption ID、T1/W0充分量和24面板已封存。实际任务FIT=64图、16面板×2流，共128条件。

## 5. Parameters

四个候选C32/A32/Q32/P32各32维、每个只求解一次。V=0.020987387803285677，gamma=5.803008138546198e-08。仿射FP32后回原BF16入口；原noise/reader precision保持。没有新增Anchor、Projector/VAE forward、大模型更新、换checkpoint、调半径或重选组。

## 6. Command

生产任务 `LatentAtlas-Q32-Micro-20261009-r1` 单次派发，原GPU/run锁持至OSwait。正式生产代码在原始ZIP `code-production-r1/`，逐调用账本 `micro-r1/ledger.jsonl`，原始scores/J `FIT_RESPONSES.npz`。独立CPU核验代码、授权私有portable代码及所有调用回执见新raw归档，不覆盖旧CPU阶段原件。

## 8. Analysis

研究缺口（research gap）是任务商空间校正能否改善未见图像的任务风险，并优于共享reward信息的A32/C32基线。当前14/16固定差分为0而AD非零，与BF16小步长分数平台相容，具体内核/驱动原因未唯一定位。不能从FIT风险下降宣称泛化或优势；不能用线性预测替代C32/A32/P32真实评价。有限数学例与真实视觉分开；U_necessity未测，novelty未建立。

## 9. Problems

直接停止原因是执行包§9.3预先固定FD科学资格失败，不是主机仍离线或小求解器崩溃。早期网络失败、数值实现RED、独立CPU旧PID误判与base64原始包读取超时均保留。后一传输只读已有ZIP成功，不重跑GPU。boot变化后PID可被shell复用，需boot/命令/OSwait共同判断。
