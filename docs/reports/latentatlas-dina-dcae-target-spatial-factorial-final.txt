# DC-AE 训练目标 × 空间接口：四格机制预实验最终报告

## 第一页：结论（600字内）

在同一批 1,008 对、28 个关联组及每组 1,000 步的固定预算下，旧配方 A 的 Accuracy 为 64.16%。只换 round-trip 教师目标的 B 为 64.43%，比 A 高 0.27 个百分点，但区间跨零，Native 排序一致率反而低 0.38 个百分点。只换空间接口的 C 为 62.82%，比 A 低 1.34 个百分点；一致率高 0.45 个百分点，但后者区间跨零。两者合用的 D 为 63.59%，比 A 低 0.57 个百分点；相对 C 高 0.77 个百分点。交互估计为 +0.50 个百分点，区间跨零。三种新配方都没有同时证实 Accuracy 与 Native 排序改善，也未达到预定的近 Native 判据；相对 Native 的 Accuracy 损失均有超过 2 个百分点的探索性证据。T1 目标降低了 B、D 到 T1 的坐标误差，却未稳定转化为所需行为。本轮只能说明固定小样本、单次初始化和 1,000 步预算下的效果；不能证明训练上限、单个空间算子的因果作用或源潜变量缺信息。下一步只建议独立预算的 A–B 训练时长对照，以检验目标收益是否受优化长度限制；本轮不自动执行。

## 坐标诊断与解释边界

B 的 EVAL 到 T1 归一化 MSE 为 0.3163，A 为 0.3351；D 为 0.3298，C 为 0.3504。到 T0 的相应误差和各自分母见主表及原始 coordinate-summary。坐标误差降低未保证 Accuracy 或 Native 排序改善。空间接口 P1 同时改变低网格、通道宽度、感受野和展开方式；不是 PixelShuffle 单算子的纯因果效应。历史空间尺寸修复涉及 96/252 张评价图像，几何亚组审计只提供相关线索，不能隔离因果。
