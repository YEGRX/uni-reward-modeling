# R18 实际 MVP 实验报告

日期：2026-10-10。最终状态：**MIXED**。本报告中的数值来自实际 CPU 运行和保存的逐 seed 结果；模拟器是真实随机评分采样，身份仍是数学模型实验，不是实际神经评分器或人类反馈。

## 1. 已完成工作与预设验收

Method V1 已实现并运行；单独消融高阶恢复、结构池化，并与均值指数、未裁剪/裁剪内容指数、网格混合 MLE、可见内容饱和估计、公开函数族回归及完整 MLE 比较。单一工程 V2 在明确阈值偏差诊断后设计，最终用完全不重叠的随机种子确认。

R1 336 个设置×40=13,440 个观测库；最终 V2 32×40=1,280 个新观测库。另保留第一次 V2 的 1,280 个相关种子观测库，撤销独立确认身份，所有实际生成合计16,000。R1 主格在运行前指定为高阶模型/binary/n1024/K4/Nb32768。

SUCCESS 要求主格 posterior KL 对内容指数和强网格 MLE 的配对区间全负，且其他设置没有系统性失稳。主格满足局部比较，但结构偏离和更强公共函数族基线暴露系统性局限，因此整体只能判 MIXED。

## 2. 数据、预算与独立单位

八个可见状态 X=(U,V,W)，U+ 概率 .3，V/W 均匀。witness 使用 R18 §6：P(Y=y|X)=[1+y(.4U+.1W)]/2，z=eta[tU+(.4+theta U+.1W)V]，theta=.08，t=0/.04/.08，eta=.1/.3125，a=.8eta。独立高阶压力模型令 Y=W，z=.08aW+amp(U,W)V，amp=.8a（U=W）或 .15a；它具有共同一阶条件均值与不同高阶指数积分，不是原稿 witness。

先抽 N=ceil(2n/.075) 个完整参考内容，再按 U/Y 标签取每格最先 n 个内容；不读评分选样。另抽 Nb 个标签，L=N+Nb，全部用于参考频率。每个被选内容 K 次条件 iid 评分；Z=.6(H−U)。binary 为 ±.6，P(+|X)=(1+z/.6)/2；ternary 为 −.6/0/+.6，P±=(.5±z/.6)/2，P0=.5。两种 law 的条件均值均为 z，且在全部配置内合法。**四格各 n 个独立内容是统计单位，K 次重复不是新增内容。**

R1 扫描 n=64/256/1024，K=1/2/4/8，Nb=0/32768，两种 law，七个模型。V1 仅 K≥2；K1 保留基线。主格 N=27307、L=60075、评分 Q=16384，每个方法完全复用这些可见内容、标签与评分。没有给方法真实 A/z/rho 或 true posterior。公开参数族基线额外使用已公开的有限函数族，属于更强结构合同，单独解释；可见状态基线只使用共同可见 X。

## 3. 直接指标与评估

主指标为真实反馈 qY 加权的 posterior KL：Σy qY(y)KL(pi_true(·|y)||pi_hat(·|y))；第二直接指标为 posterior 积分 BT 的 pair KL。NLL/Brier 含不可约标签随机性，不能当 excess。其余为 posterior/pair MSE、期望 pair accuracy、Best-of-4 regret 和运行时间。

目标 joint、A、后验、pair 和所有测试损失通过完整有限状态求和获取；不是训练损失，也没有从有限测试评分估真值。训练方法不访问目标。每格40个独立训练随机重复，配对差按相同种子计算95% t区间；全网格区间未作多重比较校正，只作描述，不能按胜负次数宣称总体统计突破。

## 7. 数值资格、失败保留与成本

原R1网格EM有5656/6720未获收敛证书，主格40/40也未获；故原始EM表不能支持强基线胜出结论。随后仅复用原观测，修复求解器，另存baseline-repair。修复后54/6720仍未达1e-7（最大1.55704e-7），相关比较标记 INCONCLUSIVE_OPTIMIZATION；主格全合格。最终V2有 6/640 grid拟合未获证书，同样保留未决。

首次V2全部1280种子与R1重叠；旧REVIEW_FOLLOWUP的独立性描述被最终REVIEW_FINAL撤回。该历史运行还保存了错误继承自V1的 likelihood 诊断，必须忽略旧 likelihood；A、posterior、pair风险不受影响。最终V2已用新A重算likelihood，所有1280观测库独立检查通过。原始文件与源码快照全部保留。

全部实际阶段共 123,084,800 次**模拟**评分抽样，实测实验 wall 249.674 秒；没有真实模型评分、GPU或付费API调用。另有无新增评分的强基线补充。分阶段成本见 `resource-ledger.csv`；报告/审阅/打包时间不混入拟合时间。所有主运行覆盖失败0，fallback已单元验证。
