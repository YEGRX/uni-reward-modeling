# 未参与方法开发的编码器：固定 REC 配方接入预实验

**结论（2026-09-26）**：候选 `nvidia/Cosmos-0.1-Tokenizer-CI8x8` 是连续图像自动编码器（AE），不是 KL-VAE。在可核验的项目开发记录中，未找到该 checkpoint 或其 latent 协议用于制定本轮配方的经验记录；这是有范围的**操作性未见**，不是对所有私人历史或上游训练数据的证明。冻结 REC 配方只用 64 张 FIT 与 64 张 VAL 同图对应、**0 个目标偏好训练标签**，使正确对应的 Reward Accuracy 达 **72.619%**，比未训练 Projector 高 **28.001 个百分点**，比固定错误对应高 **23.537 个百分点**；五项预声明收益判据的单侧 95% 下界均大于 0。Native 为 **72.817%**；正确对应低 **0.198 个百分点**，配对差中央 90% 区间 **[−1.513，+1.042] 个百分点**，Native 排序一致率 **93.411%**。因此，本轮同时支持“有注册收益”和**在预声明 2pp / 90% 容忍标准下的近原生复用**，但不证明数学等价或任意编码器通用。FLUX-REC 为 72.793%，DC-AE-REC 为 64.162%；这些只是不同编码器、既有配方与训练背景下的限定比较。两组各 1000 更新，固定 1008 对开发评价，24192 次新科学 Reward 条件；两次远端 CPU 回放七文件逐字节一致，授权本地 CPU 回放最大浮点差 6.67×10⁻¹⁶、分类相同。已知 GPU 会话累计约 3 小时 14 分，另有一次失败会话时长未知；保守计入 600 秒后仍低于本轮 6 小时停止上限。

Accuracy 为四条流各自严格大于比较后等权平均，tie 计 0。Native 一致率在 Native 非 tie 条件下按总有效条件计数；新路径 tie 计 0.5。差值和区间是对 28 个完整关联组共同抽样 20000 次的配对 bootstrap（seed `2026092501`），中央 90% 区间同时给出单侧 95% 下界。

|---|---|---:|---:|---:|---:|---:|
| Native SD3.5 | 项目既有 | 0，旧分数 | 72.817% | 0 [0, 0] | 100.000% | 不适用 |

| DC-AE-REC 正确 | 已见，旧结果 | 0，旧分数 | 64.162% | −8.656 [−11.458, −5.853] | 77.282% | 旧实验 0.309381 |

Native 准确率与 FLUX-REC 几乎相同；正确新路径比 FLUX-REC 低 0.174pp，区间 [−1.438，+1.091]pp。正确新路径比 DC-AE-REC 高 8.457pp，区间 [+5.481，+11.409]pp。不能把跨编码器差别归因于单一潜变量结构：编码器架构、压缩、训练数据和预处理同时不同。NoReg 是**未训练 Projector**，不是直接裸 latent。

## 成本、完整性与限制

两组共 2000 个优化更新；新评分 24192 条 Reward 条件、候选编码器评价时前向 0（先物化固定缓存）。正式训练 GPU 会话 **1986.89 秒**，评分 **8695.63 秒**；含准备与基准的已知累计 **11630.74 秒**。早期失败 r1 精确时长未知，按冻结规则另保守预留 600 秒，计 **12230.74 秒**，仍小于 21600 秒停止上限。远端本 run 目录约 **287,197,974 字节**，低于 30GiB 新磁盘上限；这是目录占用快照，不冒充全宿主盘容量证明。自有 GPU 已退出本轮评分进程。

评分后独立远端 CPU 审核 1008 行、六路径、每行 24 条新科学条件、身份/噪声/模型/计数与注册 128 行；正式两组检查点此前已独立核验。两次独立远端 CPU 回放的七个结果文件 **逐字节一致**。最终授权本地 portable CPU 回放以源包 SHA 为根，最大浮点差 **6.661338147750939×10⁻¹⁶**，小于预声明 `atol=rtol=1e-10`，分类一致、报告字节相同。本地控制脚本最初在结果比对时由系统 Python 缺 NumPy 而失败；重放本身已完成且原输出保留，仅以安装了 NumPy 的既有 bundled Python 对原结果做补充比对，没有重跑科学计算或改冻结规则。

限制：仅一个操作性未见编码器、一个训练 seed、一张固定错误对应；组 bootstrap 只量化这批已消费图片/标签的抽样不确定性，不提供跨编码器、训练随机性或 fresh 数据泛化证据。错误对应还可能含空间几何混杂。候选第一张 FIT 图的独立进程 latent 与完整缓存对应值非逐位相等；F0/F1 要求的进程内官方/直接等价、形状、有限性和状态检查及完整缓存的独立核验均保留，但该跨进程差异仍是复现边界。CPU 回放证明数值统计可追踪，模型语义由官方代码审计和实际 CUDA parity 支撑，并非 CPU 单独证明。
