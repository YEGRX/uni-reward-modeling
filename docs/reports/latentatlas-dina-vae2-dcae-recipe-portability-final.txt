# DC-AE 注册配方迁移小实验：最终报告

实验：`DINA_VAE2_DCAE_RECIPE_PORTABILITY_PILOT_R1`  
状态：**VERIFIED_COMPLETE**；2026-09-25 完成远端双回放、本地独立回放及最终封存。

**结论：固定 REC 注册配方迁移到第二编码器 DC-AE 后，在零目标偏好训练标签下产生了明确的 Reward 复用收益，但仍明显低于 Native，未达到本轮“接近 Native”的标准。**

正确对应准确率为 **64.16%**，高于未训练接口 **21.11 个百分点**、高于置换对应 **15.48 个百分点**；与 Native 相差 **−8.66 个百分点**。Native 排序一致率为 **77.28%**。预先声明的五项注册收益联合判据全部通过；接近 Native 的两项附加条件未通过，且有超过 2 个百分点损失的证据。

## 1. 这轮回答了什么

1. **能否接入同一 DiNa？** 可以通过新训练的 DC-AE Projector 接入；DiNa 和两个编码器保持冻结，训练没有读取目标偏好标签。接入有收益不等于无损替代。
2. **正确对应是否重要？** 正确对应相对未训练、置换对应的准确率及 Native 排序一致率改善，其配对区间下界均大于 0。
3. **是否接近 Native？** 没有。准确率差的中央 90% 区间为 [−11.51, −5.88] 个百分点；排序一致率区间为 [74.33%, 80.03%]。
4. **是否与 FLUX 同口径？** 是，五臂使用同一 1008 对、28 个关联组、4 条流及逐流正确率口径。旧 FLUX-REC 为 72.79%，本轮只复用其封存分数。
5. **做了哪些必要移植？** 输入通道 16→32、DC-AE 原生空间网格在卷积前对齐到 source 网格、参数 39,056→40,080；复用训练配方，而非复用 FLUX 权重。
6. **新增何种证据？** 支持固定 REC 配方在这个已知第二编码器上获得可读 Reward 信号；不证明任意 VAE 通用、真正未见编码器泛化或同一 Projector 权重可通用。
7. **成本？** 新增 2,000 次训练更新、24,192 个科学评分条件。正式训练占用约 33.53 分钟，正式评价约 94.20 分钟；本轮累计账本约 3.04 小时，含此前准备与失败保守预留，不等于纯计算耗时。

差值及区间单位为**百分点（pp）**；准确率和一致率单位为百分比。区间均为中央 90%。

|---|---:|---:|---|---:|---:|
| Native SD3.5 | 0 | 72.82% | 0.00 [0.00, 0.00] | 100.00% | 0 |
| FLUX 已注册（旧结果） | 0 | 72.79% | -0.02 [-1.56, 1.46] | 91.69% | NOT_AVAILABLE |
| DC-AE 未训练接口 | 0 | 43.06% | -29.76 [-34.60, -24.92] | 58.03% | 2.239122 |

## 3. 配对比较及预声明判据

| 比较 | 点估计（pp） | 中央 90% 区间（pp） | q05 > 0 |
|---|---:|---|---|
| 正确对应 − chance | 14.16 | [10.29, 17.91] | 是 |
| 正确对应 − 未训练 | 21.11 | [16.39, 25.99] | 是 |
| 正确对应 − 置换 | 15.48 | [12.03, 18.92] | 是 |
| 排序一致率：正确 − 未训练 | 19.25 | [14.26, 24.19] | 是 |
| 排序一致率：正确 − 置换 | 18.64 | [15.23, 21.99] | 是 |
| 正确对应 − Native | -8.66 | [-11.51, -5.88] | 否 |
| 正确对应 − FLUX-REC | -8.63 | [-11.61, -5.83] | 否 |

前五项下界全部 > 0，因此 `SECOND_FAMILY_REGISTERED_REWARD_SIGNAL_SUPPORTED`。
接近 Native 还要求 q05(正确−Native)>−2pp，以及 q05(Native排序一致率)>90%。本轮分别为 −11.51pp 和 74.33%，均未达到。q95(正确−Native)=−5.88pp < −2pp，因此 `LOSS_EXCEEDING_2PP_SUPPORTED`，不仅仅是区间太宽而未确立。
与 FLUX 的差值仅适用于此次共同评价，不作为两个 VAE 的普遍排名。

## 4. 固定设计、移植与指标口径

- 64 FIT、64 VAL COCO anchors；seed 20260827；正确/第一固定置换两组各 1000 更新。训练只有图像、caption 及对应 latent，不使用目标偏好标签。
- 两组使用相同初始化与样本顺序、effective batch32、相同优化器及原 12000 步学习率曲线的前 1000 步。不是将整条曲线压缩到 1000 步。
- 每 500 步保存；各自正确配对 VAL loss 选点，平局取最早。正确组选择 1000，置换组选择 500；二者终点均为 1000。
- 固定 1008 HPDv3 pairs / 28 个完整关联组 / 原 4 条噪声流；每条流先 strict-greater 判断人类偏好正确性（tie=0），再平均，未把 4 条流当独立样本。
- Native 排序一致率仅在 Native 非 tie 的条件上计算：同向 1、适配器 tie 0.5、反向 0；按总计数比率聚合。
- 20000 次共同 connected-group bootstrap，seed2026092402；每次抽 28 组，整组有放回，保持 pair-micro 权重。

| 移植项 | 本轮实现 |
|---|---|
| 编码器 | 固定官方 DC-AE f32c32 in-1.0；原 RGB；官方 FP32 tiled512/stride448；raw latent，无额外 scale/shift |
| Cin / H / W | 32通道，原生 floor 空间网格；卷积前 FP32 bilinear、align_corners=False 到 source 网格 |
| Projector | 32→64→64→16，1×1 / 3×3 / 1×1，SiLU；40,080 参数 |
| 配方 | FIT normalized MSE；原 sampler/LR/AdamW/clip；新权重、相同 seed；每组1000更新 |

## 5. 注册诊断与解释限制

正确组 VAL normalized MSE 为 0.309381，未训练为 2.239122，所选置换组为 1.087466。正确组 VAL cosine 为 0.929847，固定 64 候选的 R@1、R@5 均为 100%；这些是用于选点的 VAL 上的开发诊断，不能当独立泛化评估。
坐标层的显著改善并未消除 Reward 差距：正确组与 Native margin 的 pooled Pearson 为 0.750351、Spearman 为 0.742340，排序一致率仅 77.28%。这支持“配方可迁移并带来收益”，同时保留“当前配方和短训练尚不能近乎无损复用”的限制。
只有一个训练 seed 和一个置换；group bootstrap 不补足训练随机性或置换重复。wrong-teacher 的网格对齐有几何混杂，胜过置换不能单独证明纯因果机制。此处不推断编码器理论上限、任意 VAE 通用、true-unseen 已解决，也不自动扩大实验。

## 6. 执行、成本与核验

- 两个训练组各1000更新均独立CPU核验，检查点、自身VAL选点及七个冻结模型状态通过；每个GPU进程执行真实官方legacy+t04 parity。
- 评价完整1008对，3新臂×2图×4流=24192科学条件；正式阶段复用此前380个DC-AE编码，不重新编码。全历史技术条件147。
- 正式训练 GPU 独占占用 2011.734秒；正式评价5651.987秒，合计7663.721秒（约2.13小时），包含模型加载/校验到资源释放。全历史收费10943.881秒（约3.04小时），含旧失败1800秒保守计账；保留账本而非退款重写。
- 运行中一个父CPU核验脚本意外生成字节码缓存，已按SHA归档并移出冻结目录；修正仅父控制，全部冻结源/spec/checkpoint字节未改，生产任务未重启。
- 两个独立远端CPU进程回放输出 inventory 完全相同。最终本地独立CPU重算26个输出，分别与两份远端结果比较，最大浮点差5.551115123125783e-16，低于atol/rtol1e-10；分类完全一致。**本地数值容差内一致不称逐字节一致。**
- 分析输入与输出inventory先封存，再核验receipt，最后result seal引用前两者，无循环hash。最终seal另一次远端只读核验通过。GPU阶段已结束，资源锁已释放。
