# A–B 固定日程训练预算响应预实验｜最终报告

实验身份：`DINA_DCAE_AB_BUDGET_RESPONSE_4K_PILOT_R1`  
判定路径：`STOP_AT_2K`  
最终评价：1008 对、28 组、4 流；A2000/B2000 各侧完整评分 16128 条件。  
证据状态：原评价进程因时长守护被记为不确定；完整科学输出经补充的远端双独立 CPU 回放、第三进程复核和授权本地纯 CPU 回放一致。本报告保留该工程限制，不将原 guard 改称 clean。

## 第一页：直接结论

A 的自身目标全 VAL loss 从 1000 到 2000 步下降 **0.78%**，B 下降 **1.66%**；1500→2000 分别只下降 **0.17%**、**0.56%**。两臂都未同时达到预注册的 3% 总降幅和 1% 尾段降幅，因此在打开新 Reward 结果前封存 `STOP_AT_2K`，没有训练 2001–4000 步。固定全量评价中，A 的 Accuracy 从 **64.16%** 到 **65.18%**，增加 **1.02 个百分点**；B 从 **64.43%** 到 **64.86%**，增加 **0.42 个百分点**。B2000 比 A2000 低 **0.32 个百分点**，未显示 T1 的行为优势。两者距 Native 的 72.82% 仍差约 **7.6–8.0 个百分点**。A 的小幅行为改善与坐标误差下降同向；B 的坐标改善没有转化为明确的 Accuracy 收益。当前证据不足以将 DC-AE 缺口主要归于“再多训练即可解决”，也不能排除更远预算或其他目标、结构与空间因素。下一步如需机制判断，应另行设计目标与空间接口实验，本轮不自动扩展。

## 1. 固定协议与来源

- A：原 P0 + W0 的 T0 目标；B：相同架构和优化日程下的 T1 目标。两臂从各自封存的 1000 步完整优化器、采样器和 RNG 状态连续训练到 2000 步，seed `20260827`，每 250 步保存完整检查点与 FIT/VAL×T0/T1 诊断；无新目标偏好标签。
- 阶段门控只使用自身目标的全 VAL 归一化 MSE 在 1000、1500、2000 步的数值。决策、时间戳与封印在新增 Reward 评分前写入；独立远端 CPU 核查了终点和 `STOP_AT_2K`。旧 A1000/B1000/Native/G 逐行只读复用，未重训旧结果。
- 新评分仅使用固定 1008 对、28 个连通组、4 个噪声流。推断沿原 evaluator 的默认 backend；当前进程 legacy+t04 parity、七模型状态与科学调用计数均在完整终态证据中核验。统计采用共同 28 组、20,000 次 bootstrap，中心区间为 5%–95% 分位；预声明的联合判断另看调整后 0.5% 下界。

来源：`USER_AUTHORITY.md`、`USER_AUTHORITY_ADDENDUM_R1.md`、`ALL_RESOURCE_CAPS_REMOVED_AUTHORITY_20260928.md`、远端 `operations/formal-training-r2/decision/PHASE1_CONTINUATION_DECISION.json`、`evidence/EVALUATION_R4B_TIME_UNCERTAIN_INDEPENDENT_REMOTE_CPU.json`。

## 5. 资源、工程状态与信任边界

- 正式新训练更新：A 1000、B 1000，合计 2000；阶段二 0。最终新增正式评价科学条件 **16128**；失败的 r3 评价曾计费 **182**，累计账本 **16310**，不退款、不把失败尝试纳入固定评价集。技术 DiNa 条件累计 **138**。
- 资源上限按用户后续授权取消；原账本事件和失败收费保留。账本累计计费 GPU 秒数 **135063.193**（约 37.52 小时，含失败预约计费），不等于单次评分实际耗时。A/B benchmark 的 FIT-only 更新均值曾分别为 0.6135/0.5823 秒，不可外推为完整评价吞吐。
- 旧正式训练 r2 在终点摘要写入后的清理阶段被旧守护终止，guard `124/uncertain`；独立 CPU 从完整检查点、封存门控、当前 parity 和七状态核验了两臂 2000 终点。r3 评价工程失败，182 条件保留。r4 评价的 **1008 行、16128 条件、summary 与 final-state 完整**，worker 返回 0；然而其固定 86400 秒 guard 在 `100033.196` 秒处写入 `clean=false`，外层 exit 1、账本为 `uncertain`。先前仅延长外层 timeout 的 POSIX 计时器，没有也未改动 guard 的独立时长判断。
- 原 r4 clean-only 回放没有被伪装为通过。本轮补充核验先在远端 CPU 独立检查冻结 spec/code、1008 逐行 SHA、旧参照、门控、16128 前向计数、legacy+t04 parity、七状态前后相等；随后两次独立远端 CPU 重新计算 20k 组 bootstrap，第三进程逐文件比对，第四进程复算并导出小型便携包；授权本地纯 CPU 回放与两远端结果一致，最大绝对数值差 **6.66×10⁻¹⁶**。补充证明接受的是“完整科学输出、时间 guard 不确定”的狭窄情况，原 guard/exit/计费记录仍原样保留。它不构成对一般不完整评分的放行。

## 6. 限制与后续

样本限定于固定的 1008 对/28 组，四流和一个 seed；2K 门控限制了本轮对 4K/8K 的结论。Accuracy 的百分点增益不能解释为恢复了相同比例的潜空间信息。B2000 未体现 T1 行为优势，也未接近 Native，但本轮不能区分 projector 表达能力、优化地形、Anchor 覆盖、目标随机性、空间对应关系或当前 reconstruction objective 的贡献。若继续研究，应另行预注册有判别力的目标×空间接口实验；本轮不自动启动 FUNC、C/D、8K 或其他新实验。
