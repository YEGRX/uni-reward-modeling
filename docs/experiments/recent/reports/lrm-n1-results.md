# LRM-N1：真实Noisy-State迁移结果

**主要发现：现有REC通过当前clean estimate保留了两时点的参考选择；raw noisy直接接入在当前四轨迹中随时间出现排序失效。** 正式决定：`CLEAN_ESTIMATE_BRIDGE_ONLY`。证据等级：HISTORICAL DEVELOPMENT TRAJECTORY PILOT，2个Prompt、4条实际轨迹、8状态，无人类偏好标签。

## 6. 失败边界、归因与适用范围

当前直接REC/Affine的技术合同均通过，观察到的是功能失稳而非未执行。现有证据支持先用即时去噪估计再接入REC；它依赖当前来源模型velocity，属于clean-estimate bridge，不是raw noisy-to-noisy成功。不能从一次输入替换唯一归因到训练域、非线性噪声变换、时间匹配或信息不足中的某一个。

原参考A在本轮全部单元已经保留Final赢家，因此当前失败不必归于中间时点完全缺乏终态相关信息。此结论只覆盖这四轨迹与冻结DiNa选择；其目标人类有效性仍受R2未解决问题约束。

本轮未优化接口、噪声条件或种子，未测端到端加速或人类收益。结果生成后停止，不自动训练noisy mapper或扩样。
