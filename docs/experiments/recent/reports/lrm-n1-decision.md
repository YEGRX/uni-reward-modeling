# LRM-N1：科研决定

**正式决定：`CLEAN_ESTIMATE_BRIDGE_ONLY`。** 现有REC通过真实中间状态的当前clean estimate，在两个固定时点均保持即时及终态DiNa赢家；直接raw noisy接入未通过双时点完整资格。

证据等级：历史开发域资格/机制pilot；2个Prompt、4条真实轨迹、2时间，8状态；无总体显著性或人类质量结论。

## 为什么作此决定

按照评分前规则，B完整保持A和Final，而C/D均未完整通过，故选择clean-estimate bridge。该决定同时保留C在默认中期的2/2成功和Affine的真实表现，不将部分失败外推为所有noisy接口不可能。

最重要的新证据是：当前参考A已经保留终态赢家，接口输入换成当前估计也能保持它；raw noisy直接映射仍会在更晚时点失效。因而不能只用更小源sigma或分数偏差缩小来认定部署更可靠。尚不能唯一分离Clean训练支持域、表示噪声法则、目标时间适配及函数敏感性。
