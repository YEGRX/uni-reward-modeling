# D74 科研决定：保留功能迁移证据，停止当前预测器扩展

日期：2026-10-20。P0和D74-0已经完成，正式决定为 **`NO_GO_PREDICTION`**。对象是本轮预定的无当前任务RM查询的接口选择路线。C主论文继续以冻结RM功能复用为中心，下一优先项为独立确认；D74-1、预算预测和D74-P3均未启动。

## 本轮决定的依据

固定四组历史DEV、两噪声流、十个相关适配设置中，REC相对20候选择优的强仿射，Native agreement点估计全部提高：Cosmos五项为+5.575至+8.188个百分点，FLUX五项为+1.394至+2.613个百分点。这扩展了少Anchor功能复用的开发证据。

事前封存的坐标VAL规则在四个FLUX设置中选择Affine，因此任务等权agreement为90.157%，低于固定REC的90.889%。未形成能够改善主要选择终点的新规则。FLUX-16A还显示坐标误差、margin MSE与排序可能给出不同接口偏好；这是具体的功能诊断结果，不能用一个坐标指标替代下游验收。

证据等级：**真实模型实验＋原数组复核，已消费开发域探索。** 十个设置共享Anchor池、VAL及DEV，不是十项独立任务。仅四个统计组，七项Gagr描述区间跨零，两项删组反号；因此“全部点估计为正”不升级为总体或未见来源上的稳定支配。

## 一：REC的功能收益是否稳定存在？

本批全部十项Gagr点估计为正，八项在四次leave-one-group-out下保持正号；Cosmos-32B和FLUX-16B各有一次反号。共享设置均值为+4.443个百分点，四组描述区间[−.350,+12.125]。证据支持固定预算和数据域内的正向现象，稳定总体收益仍需独立组确认。

P0新增zero-mask仿射覆盖REC线性化的边界偏置，且保留原reflect强基线。n64的REC相对zero控制的agreement增益为Cosmos+7.317、FLUX+2.962个百分点；简单更换padding没有消除点估计优势。仍不能把配方整体优势唯一归因为激活函数或特殊Anchor几何。

Interposer-cycle仅重估BN统计就使坐标VAL NMSE下降4.779%，超过事前1%门槛。原比较可作为指定训练/推理配方的结果，暂不足以支持架构固有优越性。无BN的REC/Affine本轮资格有效；不需要据此把全部研究改判为`REASSESS_BASELINE`。

## 二：哪些纯坐标统计能预测功能收益？

X1的符号正确预测Gagr为6/10、Gmmse为8/10；它对两种终点的作用不同。这里是预定规则在同一开发批次上的验收，不是新VAE泛化率。

X2从FIT16到FIT32下降约40%，只提供两个指定Anchor集合的输出稳定性信息。没有事前功能阈值、没有n64重复bank，不能将其升级为Reward不确定性。X3净残差解释量与X1严格相同，不增加预测信息。

结论：当前没有通过主要选择价值门槛的坐标预测量。没有拟合幅度预测器，MAE/RMSE不适用。未利用结果反复添加统计量、筛通道或调阈值。

## 三：能否对未见Anchor集合产生有价值的选择？

尚未建立。本批规则未用新增RM结果拟合，具有事前评价性质；但Anchor来自固定已消费FIT64池，整个实验仍为开发研究。当前规则连批内描述平均都未超过Always REC，继续训练高容量元预测器缺乏准入依据。

未来重启至少需要一个具有独立信息和清楚成本来源的规则，并先在新Anchor集合上出现可复现的选择差异；然后在新评价组确认。单靠来源标识、同一数据上的相关性或重定义成功指标不足以重启。

## 四：哪些条件需要更大Anchor预算？

当前不能给出可靠条件。FIT16→32降低集合输出差异，部分功能指标也改善，但曲线不单调：Cosmos-32A的REC agreement高于64；FLUX-32B的MMSE优于64。相同预算的bank差异、短训练配方和坐标选模共同影响结果。

同一组/流的旧正式REC结果优于1000步前缀，表明增加训练与增加Anchor必须区分。本轮没有事前绝对agreement目标、有效代价函数和未消费多bank样本，故不选择`GO_BUDGET_PREDICTION`。先补论文独立确认的价值更明确。

## 五：收益是否超过额外成本？

没有证据支持。本批先训练REC和Affine才计算X1；X2还需要两bank拟合。它没有节省已付出的训练，且单任务仍使用n+64张配对图像。预定策略的当前任务RM输入均为0；Always REC本身也为0，因此不能声称相对它节省Reward查询。

实测主要选择损失：Always REC为0，Coordinate VAL为.732个百分点，Always Affine为4.443个百分点，均为十个相关设置的等权描述。Affine训练与部署成本可能更低，但尚未定义质量—成本交换率，也没有同硬件端到端延迟比较，不能据此宣布综合效用最优。研究评价的13,072次RM调用独立核账。

## 六：与前作相比新增什么？

Csiszárik等已比较表示匹配与功能匹配；Insulla等研究alignment与stitching risk的关系；KLAS已有通过表征指标预测连接质量和选择配置的框架。相关原文与本轮阅读范围见`D74_THEORY.md`。这些工作使“坐标不等于功能”或“预测stitching质量”本身不足以构成新贡献。

本轮真实增量是：在完全冻结DiNa、无RM训练监督、强仿射及边界控制、明确少图像预算下，实际检验了坐标规则的选择价值，并定位一个坐标/分差/排序偏好分离的真实案例。四项数学命题完成了信息边界和决策损失连接，未建立新的DiNa预测定理。

这适合作为C论文的系统性实证与适用边界补强；目前不足以作为独立预测算法论文，也未达到将D74更名为主论文核心方法的条件。

## 七：下一项最值得做的实验

**冻结C的正式REC与强Affine，确认在未参与研究的新候选组上，REC的功能收益能否复现。** 先完成新数据身份与消费记录，再执行；不额外训练接口，不以D74四组结果重新选checkpoint。

建议固定两个来源、同组同噪声、主终点Gagr，MMSE与Native选择损失为分开的次终点。以prompt/候选组为统计单位，保留candidate相关性、Native tie和BF16合同。原正式FIT64/VAL64与checkpoint可直接复用；C的固定方法确认不要求新增Anchor，D74预测器确认才要求新bank和新组。

一个可计量的准备规模是32个完整K9组（288图、1152物理对）、四流、五条评分路径：共同Native一次、两来源各REC与Affine。按原pair侧/流合同科学评分为32×36×4×2×5=46,080单图RM调用；接口预测4×288=1,152次，训练0。技术资格与新数据编码另列，不能藏入这个科学调用数。**这不是已冻结或已启动的执行预算**：当前尚无合格新组清单，编码合同与技术额度须在看到新结果前固定；不能挪用已消费source400来凑数。

资格与停止规则：先完成身份、prompt/RGB排重及全部历史消费审查；数据污染或合同错配立即停止。一次固定评价，不因区间不理想追加组或改checkpoint。两来源事前分开的Gagr及组级区间决定方向：独立复现则加强C主要结论；明显反向则重审适用域和方法；区间未分辨则如实报告并转向论文证据强度评估，而不是自动追加机制搜索。

当前已审索引的状态为`NOT_READY_FROM_REVIEWED_ASSETS`：source400全部用于历史qualification；旧SVG及额外S256 Anchor亦有消费记录。本轮不读取待确认分数，P3科学调用0。该资产结论限于已审入口，不声称所有可能外部数据都不存在。

## 竞争解释与决定边界

| 解释 | 本轮实际证据 | 仍未识别 |
|---|---|---|
| H0 普通拟合/结构/优化 | 强Affine、边界控制与旧5000步结果提供具体对照 | 非线性、正则化与优化的独立因果贡献 |
| H1 有用非线性功能修正 | REC在十项agreement点估计胜出 | 特殊Anchor机制及功能方向的可提前识别性 |
| H2 少样本估计代价 | FIT32的A/B输出差异下降 | 总偏差、未见bank风险及预算阈值 |
| H3 margin和误差差分 | FLUX-16A的MMSE恶化主要发生于排序credit不变项，排序仍净改善 | 误差方向由何种表示机制产生 |

四种解释可以共存。停止的是当前没有决策增量的预测扩展；C论文的功能实验价值与独立确认任务继续保留。
